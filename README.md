# Fractal-lantern-ia

# IA Fractale - Moteur Déterministe Local (V8.8)

L'IA Fractale est un prototype fonctionnel d'**agent d'extraction et de filtrage ascétique**, conçu pour l'informatique de poche déconnectée (testé sous iOS a-Shell). 

À l'exact opposé des modèles de langage (LLM) probabilistes qui parient sur le mot suivant et risquent l'hallucination, cet outil applique l'axiome central : **`[Cohérence = Survie]`**.

## 🛡️ Principes Fondamentaux
1. **Clôture Logique :** Recherche en priorité absolue dans un savoir immanent confiné (`corpus.txt`).
2. **Filtrage de la Donnée :** Extraction clinique via les API Wikipédia et ArXiv en éliminant la rhétorique (nettoyage des balises HTML et structures de contrôle).
3. **Suprématie du Silence :** Face au vide, à l'incertitude ou aux pannes de réseau, l'agent ne spécule pas, ne parie pas. **Il se tait et rend la main.**

## 🚀 Utilisation
1. Placez un fichier nommé `corpus.txt` dans le même dossier que le script.
2. Lancez l'agent :
   ```bash
   python3 fractal_lantern_core.py
   ```
